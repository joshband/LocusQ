Topic Prior Review Said Second Opinion
Axis flip location Hide axis inversion in Lab ★ Wrong tier. Axis flip is a first-run problem. If it's wrong, nothing works. Belongs in Focus with a clear label, not expert Lab.

Synthetic mode Not mentioned at all ★ Critical miss. Companion runs synthetic motion by default for testing. Operators must know. Visible warning in Focus required.
Token drift Not addressed ★ Design tokens (44px header, Avenir Next, #06080B bg) diverge from live HTML. Either adopt token values or document the delta.
Stale pose in render trust Not mentioned in authority card spec ★ "No pose received for N seconds" should appear in Why Changed — it's not just a Lab metric. It directly explains active render degradation.
RENDERER restructuring scope Merge authority + output summary into one top card Agreed on direction but too timid. Need to explicitly kill: Scene Monitor card, secondary routing cards, and Parity panel from the default view. Not just "merge."
Match score display Show profile match in capture flow Also show match score in the active profile summary (Step 4). "Personalized (94%)" is more informative than just "Personalized."
Plugin ack step Readiness funnel stops at send gate Add "Plugin Ack" as the 5th readiness step. It closes the loop and tells the operator the plugin is actually receiving data.
